## Overview

NVIDIA NGC Catalog is a hub of GPU-optimized software for AI, data science, and HPC workloads.

## Features

- GPU-optimized containers for PyTorch, TensorFlow, TensorRT, CUDA
- Pre-trained models and model collections
- SDKs and Helm charts for deployment
- NVIDIA-curated and verified software
- CLI and API access

## Pricing

Free. Many resources are free to use; some enterprise offerings may require NVIDIA AI Enterprise subscription.
