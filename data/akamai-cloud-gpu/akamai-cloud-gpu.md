## Overview

Akamai Cloud GPU provides GPU-accelerated instances and managed Kubernetes nodes for AI, ML, and graphics workloads on the Akamai cloud platform.

## GPU Options

- NVIDIA RTX PRO 6000 Blackwell
- NVIDIA L40S

## Features

- GPU instances and managed Kubernetes (LKE) nodes
- Akamai's global edge network
- AI and graphics workloads

## Pricing

Paid. Pricing varies by GPU type, instance configuration, and region.
