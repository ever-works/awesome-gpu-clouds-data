## Overview

gpu.nz is a GPU cloud provider focused on AI and machine learning workloads, offering on-demand GPU rental through a web interface and programmatic access.

## Key Features

- On-demand GPU instances for AI training and inference
- GPU availability lookup and VRAM estimation tools
- MCP (Model Context Protocol) server enabling AI agents (Claude, Cursor, Codex) to find GPUs, rent, monitor, and stop GPU servers
- Hosted MCP server, free to use, no API key required
- Per-second or hourly metered billing for compute

## Pricing Model

Paid cloud GPU rental; compute is billed by usage. The hosted MCP server for AI agents is free and requires no API key.

## Deployment

Cloud-hosted GPU instances; accessed via web console, CLI, or MCP integrations.

## Integrations

- Claude Code
- Cursor
- Codex CLI
- MCP-compatible AI agents
