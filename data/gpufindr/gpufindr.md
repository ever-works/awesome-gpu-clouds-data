## Overview

GPUFindr is a live price comparison tool for GPU cloud providers, aggregating pricing from CoreWeave, Lambda, RunPod, Vast.ai, and other GPU clouds.

## Features

- Live price comparison across multiple GPU clouds
- Free API for programmatic access
- MCP server integration
- Coverage of CoreWeave, Lambda, RunPod, Vast.ai, and more

## Pricing

Free. Offers a free API and MCP server for price comparison.
