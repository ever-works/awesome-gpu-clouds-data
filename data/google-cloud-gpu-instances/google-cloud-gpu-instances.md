## Overview

Google Cloud GPU Instances provide NVIDIA GPU-accelerated VMs for AI, ML, and HPC workloads on Google Cloud Platform.

## GPU Instance Families

- A3: NVIDIA H100 GPUs
- A3 Ultra: NVIDIA H200 GPUs
- A4: NVIDIA B200 GPUs
- A4X: NVIDIA GB200 GPUs
- G2: NVIDIA L4 GPUs
- G4: NVIDIA RTX PRO 6000 GPUs

## Features

- Integration with Vertex AI for model training and serving
- Google Kubernetes Engine (GKE) support for containerized GPU workloads
- TPU integration for ML workloads
- Multiple machine types optimized for different GPU generations

## Pricing

Paid. On-demand, committed use, and spot pricing available. Rates vary by GPU type, region, and commitment.
