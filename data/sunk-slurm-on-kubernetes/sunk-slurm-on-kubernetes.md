## Overview

SUNK (Slurm on Kubernetes) is CoreWeave's solution for running HPC and AI training workloads on Kubernetes clusters using Slurm workload scheduling.

## Features

- Slurm workload scheduling on Kubernetes
- HPC and AI training on the same cluster
- Bare-metal GPU node support
- InfiniBand networking integration
- CoreWeave Kubernetes-native infrastructure

## Pricing

Paid. Pricing based on CoreWeave GPU instance usage and cluster configuration.
