## Overview

Alibaba Cloud GPU provides GPU-accelerated Elastic Compute Service (ECS) instances for AI, machine learning, and rendering workloads, primarily in Asia-Pacific regions.

## GPU Instance Types

- GN7: NVIDIA A10 GPUs
- GN10e: NVIDIA V100 GPUs

## Features

- GPU-accelerated ECS instances
- AI and rendering workloads
- Asia-Pacific region focus

## Pricing

Paid. Pricing varies by instance type, region, and usage model.
