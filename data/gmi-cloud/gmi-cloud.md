## Overview

GMI Cloud is a GPU cloud provider offering H100, H200, B200, and GB200 clusters with managed Kubernetes for AI workloads.

## Features

- NVIDIA H100, H200, B200, and GB200 clusters
- Managed Kubernetes for GPU workloads
- Large-scale AI training and inference
- GPU cluster deployment

## Pricing

Paid. Pricing varies by GPU type, cluster configuration, and usage duration.
