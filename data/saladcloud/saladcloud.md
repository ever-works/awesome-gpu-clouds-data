## Overview

SaladCloud is a distributed cloud platform that leverages consumer gaming GPUs across 450,000+ provider nodes for low-cost GPU computing.

## Features

- Distributed cloud using consumer gaming GPUs
- 450,000+ provider nodes
- Containerized workloads
- Low-cost GPU instances

## Pricing

Paid. RTX 4090 from ~$0.16/hr, H100 from ~$0.99/hr.
