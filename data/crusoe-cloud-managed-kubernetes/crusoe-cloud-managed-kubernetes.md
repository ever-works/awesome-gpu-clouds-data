## Overview

Crusoe Cloud Managed Kubernetes is a managed Kubernetes service for GPU and CPU workloads, featuring InfiniBand-backed clusters for AI and HPC workloads.

## Features

- Managed Kubernetes for GPU and CPU workloads
- InfiniBand-backed clusters
- AI training and inference workloads
- Stranded and renewable energy-powered infrastructure

## Pricing

Paid. Pricing varies by cluster configuration, GPU type, and usage duration.
