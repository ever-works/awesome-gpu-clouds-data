## Overview

Koyeb is a serverless cloud platform offering global GPU deployment with scale-to-zero functionality for AI and machine learning workloads.

## GPU Options

- NVIDIA H100
- NVIDIA A100
- Tenstorrent accelerators

## Features

- Serverless GPU deployment
- Scale-to-zero to minimize costs
- Global deployment across multiple regions
- Request-driven and job-based GPU workloads

## Pricing

Paid. A100 approximately $2/hr, H100 approximately $3.30/hr.
