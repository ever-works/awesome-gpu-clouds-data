## Overview

Azure NC/ND GPU Virtual Machines provide GPU-accelerated compute for AI training, inference, HPC, and graphics workloads on Microsoft Azure.

## GPU VM Series

- NCads H100 v5: NVIDIA H100 GPUs
- ND H100 v5: NVIDIA H100 GPUs with InfiniBand
- NC A100 v4: NVIDIA A100 GPUs
- NVads A10 v5: NVIDIA A10 GPUs

## Features

- InfiniBand networking options for high-performance interconnect
- Suitable for Windows/Linux workstations and Azure ML training
- Integration with Azure Machine Learning and Azure Kubernetes Service
- Multiple VM sizes for different workload requirements

## Pricing

Paid. On-demand, reserved, and spot pricing available. Rates vary by VM size, region, and commitment term.
