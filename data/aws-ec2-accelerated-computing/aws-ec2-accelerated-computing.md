## Overview

AWS EC2 Accelerated Computing provides GPU-accelerated instance types for machine learning, HPC, and graphics workloads.

## GPU Instance Families

- P5/P5e: NVIDIA H100/H200 GPUs
- P4d: NVIDIA A100 GPUs
- G6e: NVIDIA L40S GPUs
- Trn1/Trn2: AWS Trainium accelerators
- Inf1/Inf2: AWS Inferentia accelerators

## Features

- Elastic Fabric Adapter (EFA) networking for low-latency multi-node training
- EC2 UltraClusters for large-scale distributed training
- Multiple purchasing options: on-demand, spot, reserved, and capacity blocks
- Integration with AWS ecosystem including SageMaker, ECS, and EKS

## Pricing

Paid. On-demand, spot, reserved instances, and capacity blocks available. Pricing varies by instance type, region, and commitment term.
