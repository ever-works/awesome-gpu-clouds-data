## Overview

MosaicML Foundry is an open-source training framework for large language models from 125M to 70B+ parameters.

## Features

- Open-source LLM training framework
- Support for models from 125M to 70B+ parameters
- Distributed training capabilities
- Fine-tuning and pre-training workflows
- Composer-based training library
- Integration with MosaicML platform
