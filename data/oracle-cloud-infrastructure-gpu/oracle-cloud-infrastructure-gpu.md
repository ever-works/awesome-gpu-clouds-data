## Overview

Oracle Cloud Infrastructure GPU provides NVIDIA and AMD GPU-accelerated bare-metal and virtual machine instances for AI, ML, and HPC workloads.

## GPU Options

- NVIDIA H100, H200, A100, L40S
- AMD MI300X

## Features

- Bare-metal and VM instance options
- RDMA cluster networking for high-performance interconnect
- Competitive pricing compared to AWS, GCP, and Azure
- Free egress tiers

## Pricing

Paid. Often priced below equivalent AWS/GCP/Azure shapes. Free egress tiers available.
